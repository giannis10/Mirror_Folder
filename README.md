# Mirror_Folder
Αυτό το πρόγραμμα επιτρέπει τη σύγκριση δύο φακέλων και την εύρεση κοινών αρχείων. Ο χρήστης μπορεί να επιλέξει ποια κοινά αρχεία θέλει να διαγράψει από τον πρώτο φάκελο, με τη δυνατότητα να διαγραφούν όλα τα κοινά αρχεία με ένα μόνο κλικ.

## Χαρακτηριστικά:

- **Εύρεση Κοινών Αρχείων**: Συγκρίνει δύο φακέλους και βρίσκει τα κοινά αρχεία με βάση το όνομα τους.
- **Διαγραφή Αρχείων**: Επιτρέπει στον χρήστη να διαγράψει επιλεγμένα κοινά αρχεία από τον πρώτο φάκελο.
- **Διαγραφή Όλων των Αρχείων**: Προσφέρει την επιλογή για διαγραφή όλων των κοινών αρχείων από τον πρώτο φάκελο.
- **Ενημέρωση Στην Εξελικτική Διαδικασία**: Εμφανίζει ποσοστό ολοκλήρωσης της διαδικασίας σύγκρισης μέσω μιας γραμμής προόδου.

## Οδηγίες Χρήσης:

1. Εισάγετε τους δύο φακέλους που θέλετε να συγκρίνετε.
2. Πατήστε το κουμπί "Εύρεση Κοινών Αρχείων".
3. Επιλέξτε τα αρχεία που θέλετε να διαγράψετε από τον πρώτο φάκελο.
4. Πατήστε το κουμπί "Διαγραφή" για να τα διαγράψετε.
5. Εναλλακτικά, μπορείτε να επιλέξετε να διαγράψετε όλα τα κοινά αρχεία από τον πρώτο φάκελο.
